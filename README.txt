افتح index.html لمشاهدة الموقع، أو ارفع الملفات كما هي إلى استضافتك.
الموقع مبني بـ HTML وCSS وJavaScript، ويحتوي على جميع الصور محليًا.
لتعديل الألوان والتنسيق: assets/site.css
لتعديل بيانات التواصل: assets/config.js
الصفحات قابلة للتعديل مباشرة في ملفات HTML.

نموذج الطلب الحالي يجهز ملخصًا ويمكن نسخه أو تنزيله، لكنه لا يرسل رسالة إلى الشركة.
بعد إدخال البريد الحقيقي في assets/config.js، يظهر زر يفتح برنامج البريد لدى الزائر لإرسال الطلب بنفسه.
الإرسال المباشر يحتاج ربط خدمة بريد أو برمجة على الاستضافة.

صفحتا Impressum وDatenschutz مسودتان تحتاجان بيانات الشركة الحقيقية والمراجعة.
المعاينة معدة لمنع فهرسة محركات البحث. عند الإطلاق العام بعد إكمال البيانات، حدّث روابط canonical وog:url وog:image إلى الدومين الحقيقي، وعدّل robots.txt ووسم robots في الصفحات.
